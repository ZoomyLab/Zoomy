# Zoomy — Claude Code behaviour guide

These notes apply to every Claude Code session run inside this repository.

## Git commits

**Never add a `Co-Authored-By: Claude ...` trailer to commit messages.**
AI assistance is acknowledged in a separate section of the project, not by
tagging every commit. Write commits in the regular repository style only.

If a prior message got one, don't rewrite history — just stop adding them
going forward.
