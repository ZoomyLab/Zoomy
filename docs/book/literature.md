# Literature

Zoomy implements shallow-water, shallow-moment and vertically averaged models, finite-volume reconstruction, flux, time-stepping and projection methods, and linear and nonlinear solvers; this page lists the publications they follow, and the docstrings of the implementing functions cite these entries by DOI. The software Zoomy builds on is credited on the [Acknowledgements](acknowledgements.md) page.
