# About

Zoomy is a flexible modeling and simulation framework for free-surface flows. It
carries a model from a **symbolic** description all the way to a **numerical**
solve across a range of backends — NumPy, JAX, Firedrake, FEniCSx, OpenFOAM and
AMReX.

## Contributors

Zoomy is developed at the [Chair of Methods for Model-based Development in
Computational Engineering (MBD)](https://www.mbd.rwth-aachen.de/), the group of
[Prof. Julia Kowalski](https://www.mbd.rwth-aachen.de/cms/mbd/der-lehrstuhl/team/~qashd/julia-kowalski/?allou=1&lidx=1)
at RWTH Aachen University. The project was kicked off during the PhD project of
[Ingo Steldermann](https://www.mbd.rwth-aachen.de/cms/mbd/der-lehrstuhl/team/~qqpkz/ingo-steldermann/?allou=1&lidx=1).

- **Prof. Julia Kowalski** — head of chair
- **Ingo Steldermann** — main developer

The source code is available on [GitHub](https://github.com/ZoomyLab/Zoomy).
